MMA dans le navigateur

Le vrai moteur MMA (Musical MIDI Accompaniment) tourne ici entièrement côté client, via Pyodide — pas de réimplémentation, c'est le même code Python que la version installée en ligne de commande, avec toute sa bibliothèque de styles. Entre une grille d'accords et un nom de groove, le moteur calcule le vrai arrangement.

Grille (12 mesures)

À propos de ce portage

Le dossier usr/share/mma livré avec cette page contient le moteur MMA (MMA/*.py) et l'intégralité de sa bibliothèque de styles (lib/), copiés tels quels depuis une installation MMA réelle — y compris la base .mmaDB qui permet d'écrire juste Groove NomDuStyle sans avoir à préciser quel fichier le définit. Le MIDI produit est ensuite décodé par un petit analyseur écrit pour cette page afin d'en tirer une partition ; le fichier MIDI original reste téléchargeable tel que MMA l'a réellement généré.
